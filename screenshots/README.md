# Evidence capture

This directory is reserved for genuine screenshots or a 2–3 minute screen recording captured after running the application locally. No fabricated screenshots are included.

Suggested capture sequence:
1. Register a new account and sign in.
2. Add a glucose reading for each of the four slots.
3. Show a validation message for an invalid value or duplicate slot.
4. Edit and delete a reading.
5. Show the daily, month-to-date, and previous-month report views.
6. Show the app at a narrow/mobile viewport.
